# Voiceover script: "Product demos, recorded by an agent"

Record it in one take with a short pause between lines, then run `python3 ../../scripts/split-voiceover.py <file> script.json vo`.

```
1. HOOK
What if your product demo recorded itself?

2. PROMPT
Tell the agent what to show, in plain words.

3. BROWSER CONTROL
It opens a real browser and drives it with Playwright. Every click and keystroke, captured frame by frame.

4. POLISH
Then it zooms in where the action is, and adds captions and motion.

5. BRAND
Your colours and fonts come in automatically.

6. HOW IT WORKS
Shot list, Playwright, HyperFrames. One command, one video.

7. CTA
It's open source. Clone it, and point it at your product.
```
